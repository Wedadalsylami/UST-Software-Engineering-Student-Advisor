# UST Software Engineering Student Advisor

An AI-powered academic advisor designed to support Software Engineering students at the University of Science and Technology, Sana’a, using real academic data.

## Features

- Retrieves course information and prerequisites.
- Helps students understand prerequisite relationships.
- Avoids unsupported answers when reliable information is unavailable.
